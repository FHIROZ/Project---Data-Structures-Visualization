# Data Structure Visualizations

## 📌 Overview

Data Structure Visualizations is an interactive web-based project designed to help students and developers understand fundamental data structures through dynamic visual representations. Users can explore structures such as arrays, linked lists, trees, graphs, stacks, and queues, along with sorting algorithms, through an intuitive and interactive interface.

## ✨ Features

- Dark/Light Mode Toggle 🌗 for better user experience
- Interactive Visualizations 🎨 for Arrays, Linked Lists, Trees, Graphs, Stacks, and Queues
- Sorting Algorithm Demonstrations 🔢 including Bubble Sort, Merge Sort, and Quick Sort
- User Input & Dynamic Operations 📝 such as insertion, deletion, traversal, and searching
- Canvas-Based Animations 🖌️ for a clear understanding of data structures in action
- Responsive Design 📱 for optimal usage on different devices

## 🚀 Technologies Used

- HTML5 - Structure
- CSS3 - Styling (Dark/Light Mode)
- JavaScript (ES6) - Logic & Animations
- Canvas API - Visual Representations

## 📥 Installation & Setup

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/Data-Structure-Visualizations.git
   ```
2. Navigate into the project directory
   ```bash
   cd Data-Structure-Visualizations
   ```
3. Open `index.html` in a browser
   ```
   Open index.html in your preferred browser.
   ```

## 🎮 Usage Instructions

1. Navigate through different data structures using the menu.
2. Perform operations like insert, delete, and traverse in stacks, queues, trees, etc.
3. Switch between Light and Dark mode using the theme toggle button.
4. Interact with sorting algorithms to see step-by-step sorting processes.
